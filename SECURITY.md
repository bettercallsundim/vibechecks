# Security Policy

This project is mostly guidance and static HTML, but security-sensitive failures are welcome as taxonomy issues.

## Reporting

If you find a problem that could expose secrets, enable injection, encourage unsafe destructive operations, or otherwise make AI-generated code materially less safe, open an issue with:

- the risky pattern,
- a minimal bad example,
- a safer example,
- which principle should catch it.

Do not include live secrets, private logs, customer data, or exploit details from systems you do not own.
